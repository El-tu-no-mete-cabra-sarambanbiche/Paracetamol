# HotelTech — Landing de soluciones para hoteles

Pequeña landing de ventas pensada para ofrecer servicios a hoteles: reservas directas, upsell, check-in exprés y analítica.

Contenido:
- `hotel.html` — página principal de la demo
- `assets/style.css` — estilos principales
- `assets/script.js` — interacciones (menú, validación de formulario)
- `assets/*.svg` — imágenes placeholder

Cómo ver localmente:

1. Abrir `hotel.html` en el navegador (doble clic o `File → Open`).
